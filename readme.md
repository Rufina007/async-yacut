# YaCut

Сервис для сокращения ссылок. Позволяет создать короткую ссылку на любой
длинный URL — автоматически или по собственному варианту, а также загрузить
несколько файлов на Яндекс Диск и получить короткие ссылки для их скачивания.

## Возможности

- Создание короткой ссылки на длинный URL, с собственным вариантом короткого
  идентификатора или автогенерацией.
- Переход по короткой ссылке — переадресация на исходный адрес.
- Асинхронная загрузка нескольких файлов на Яндекс Диск через REST API
  Яндекс Диска, с генерацией короткой ссылки для скачивания каждого файла.
- REST API для внешних сервисов:
  - `POST /api/id/` — создание короткой ссылки;
  - `GET /api/id/<short_id>/` — получение оригинальной ссылки по короткому
    идентификатору.

Полная спецификация API — в файле `openapi.yml`.

## Стек технологий

Python 3, Flask, Flask-SQLAlchemy, Flask-Migrate, Flask-WTF, SQLite,
aiohttp (асинхронные запросы к API Яндекс Диска), pytest.

## Как развернуть проект

Клонировать репозиторий и перейти в него в командной строке:

```
git clone git@github.com:Rufina007/async-yacut.git
```

```
cd async-yacut
```

Создать и активировать виртуальное окружение:

```
python3 -m venv venv
```

- Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

- Если у вас Windows

    ```
    source venv/Scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Создать в директории проекта файл `.env` со следующими переменными
окружения:

```
FLASK_APP=yacut
FLASK_DEBUG=1
SECRET_KEY=<секретный ключ Flask-приложения>
DATABASE_URI=sqlite:///db.sqlite3
DISK_TOKEN=<OAuth-токен приложения Яндекс Диска>
```

`DISK_TOKEN` нужен только для реальной загрузки файлов через `/files` —
получить его можно, создав приложение на
[oauth.yandex.ru](https://oauth.yandex.ru) с правами
`cloud_api:disk.app_folder` и `cloud_api:disk.info`.

Создать базу данных и применить миграции:

```
flask db upgrade
```

Запустить проект:

```
flask run
```
